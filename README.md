# NetSimClient 
## 상태 : 진행 중(프로토 타입)

### 연관 프로젝트
+ 백앤드 서버 : [NetSim (Dedicated Server)](<https://github.com/LEEHAESUGIT/NetSim>)

# 개발환경
+ Engine : Unity 6000.3.9f1
+ IDE : Visual Studio 2022
+ Language & Runtime : C#(.NET 8.0 호환 / C# 12+)


# 소개
"NetSimClient"는 직접 구축한 C# 데디케이티드 권위형 서버(NetSim)와의 비동기 소켓 통신을 검증하고 네트워크 동기화 기법(클라이언트 예측 , 보간 등) 을 연구하기 위해 제작 중인 Unity 기반의 프로토타입 클라이언트 입니다.

상용 네트워크 엔진에 의존하지 않고, 자체 설계한 바이너리 패킷 프로토콜을 유니티 메인 스레드 및 라이프 사이클(MonobeHaviour)환경에 맞춰 완벽하게 이식 하는것을 목표로 개발하고 있습니다.
